# Architecture

Last updated: 2026-11-03

## 1. Shape

```
┌─────────────────┐   HTTPS    ┌──────────────────────────────┐
│ apps/mobile     │ ─────────► │ apps/api (Bun + Hono)        │
│ Expo / RN       │            │  /api/*   public + auth      │
│ Arabic-first    │            │  /admin   admin SPA          │
└─────────────────┘            └──────────┬───────────────────┘
                                          │ Drizzle
                                   ┌──────▼──────┐
                                   │ PostgreSQL  │
                                   │  :5433 dev  │
                                   └──────▲──────┘
                                          │
                              ┌───────────┴────────────┐
                              │ apps/worker            │
                              │ scheduler + CLI jobs   │
                              └───────────┬────────────┘
                                          │
              TradingView scanner · Yahoo · RSS · fxratesapi · NVIDIA NIM
```

- **apps/api** — read API for the app, AI chat, admin endpoints. Stateless.
- **apps/worker** — writes market data. Runs as a long-lived scheduler in prod and
  as a CLI locally (`bun src/cli.ts <job>`).
- **apps/mobile** — Expo Router app; all data through the deployed API.
- **packages/contracts** — Zod schemas are the single source of truth; OpenAPI is
  generated from the API and mobile types from OpenAPI.

## 2. Data flow

```
TradingView ──► universe / quotes / fundamentals ─┐
Yahoo       ──► daily bars ───────────────────────┤
RSS (Arab Finance, etc.) ──► news ────────────────┤──► PostgreSQL ──► API ──► mobile
fxratesapi / TradingView ──► macro_quotes ────────┤
NVIDIA NIM  ──► news analysis (queue) ────────────┘
```

AI chat is read-only over the same tables plus `ai-context.ts` builders. The model
never writes to the database.

## 3. Market scope

**EGX only.** Saudi and international instruments, news regions and UI were
removed on 2026-11-03; the `instruments.market` column was dropped in migration
`0010`. The worker fetches the TradingView `egypt` universe, quotes are in EGP,
news is Egypt-only, and there is no market selector in the app.

## 6. Auth

Better Auth with email OTP (no passwords) and optional Google. Mobile uses the
Expo plugin; sessions are 30 days. Admin endpoints additionally require
`user.is_admin`.

## 7. AI

Provider: NVIDIA NIM (`integrate.api.nvidia.com/v1`), shared `NVIDIA_API_KEY`.
- Chat: `apps/api/src/lib/nim.ts` + `routes/ai.ts`.
- Grounding: `apps/api/src/lib/ai-context.ts` builds ticker/market context from SQL.
- Entity resolution: exact ticker → normalized Arabic/English name search →
  `[[GROUND:TICKER]]` re-ground.
- News analysis: worker queue, separate prompts.
- Rule: numbers come from SQL; documents only supply narrative and citations.

## 8. Deploy

Prod host `139.185.55.63` (954 MB micro). GHCR pulls starve the box, so the
working path is:

```sh
docker build -f apps/api/Dockerfile -t egx-api .
docker save egx-api | gzip > /tmp/egx-api.tar.gz
scp /tmp/egx-api.tar.gz ubuntu@139.185.55.63:/tmp/
ssh ubuntu@139.185.55.63 'docker load -i /tmp/egx-api.tar.gz && cd /srv/egx && docker compose up -d egx-api'
```

Worker image is built the same way. Compose runs `db`, `egx-api`, `egx-worker`.

## 9. Constraints and gotchas

- **EGX website** sits behind F5 bot protection. Do not build scrapers against it;
  documents are uploaded manually by the admin for legal reasons.
- **TradingView** EGX feed is delayed ~15–20 min by the exchange; the app shows
  `asOf` and never hides staleness.
- **USD/EGP** is intentionally not taken from TradingView (static reference rate);
  fxratesapi with a jsDelivr fallback is used instead.
- **Arabic text extraction** from PDFs is unreliable with plain text extractors
  (presentation forms, bidi marks). Use coordinate- or vision-based extraction.
- **Server memory** is small: avoid parallel heavy builds; deploy images, not sources.
